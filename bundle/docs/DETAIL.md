# 待办

一个 DeepSeek Harness 的待办与日程面板。左侧是清单与日历，右侧是常驻的 AI 助手。

## 它做什么

- **列表视图**：按 逾期 / 今天 / 本周 / 以后 / 未排期 分组；标签筛选；行内勾选、删除、撤销。
- **日历视图**：7×6 月网格，含农历日、二十四节气、传统节日；滚轮翻月、年月选择器、本月回跳。
- **AI 助手**：把粘贴的截图或一句口语直接拆成待办草案，缺字段标出来由你补，补齐后一键创建。
  它同时会就时间安排和状态给建议，但只在识别到待办时才产出结构化结果。

## 怎么用

1. 在侧栏点「待办」图标打开面板。
2. 在右侧输入框里 **粘贴一张截图**，或直接说「明天下午三点跟王工对接口」。
3. 助手会给出草案卡：日期 / 时间 / 标签 / 重要 / 紧急。缺日期的字段是橙色虚线，点开补上。
4. 「全部创建」把草案写进清单。

## 模型

默认**跟随 DSH 的默认模型**，不需要单独配置，也不需要填任何 API Key。
如果想让助手用别的模型，点输入框上方的模型胶囊切换；选择会持久保存，也可随时切回「跟随 DSH 默认」。

当前版本可用的模型必须支持图片，才能用截图功能；选择器里会给支持的模型标「图片」。

## 数据放在哪

待办、对话、插件设置都存在 DSH 的存储域里（`context.storageDomain`），
不写工作区文件，也不会上传任何第三方服务（除了把你要识别的文本/图片发给模型本身）。

## 已知限制

- 农历表覆盖 1900–2100 年，超出范围不显示农历。
- 法定节假日与调休需要按年维护数据，当前版本不标注「休 / 班」。
- 助手不做医疗诊断；涉及健康状况时只会建议寻求专业帮助。
- 拖拽改期、窗口内多选等交互尚未实现。

## 开发

仓库里的 `design/` 是设计原型与本地预览（`design/harness/index.html` 可直接在浏览器打开，
用假数据渲染同一份 `bundle/client.js`）。`tools/lunar-gen/gen.mjs` 用于重新生成历法表。

```sh
node tools/lunar-gen/gen.mjs        # 重新生成并自校验农历表
```
