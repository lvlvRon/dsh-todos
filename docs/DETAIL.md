# 待办

一个 DeepSeek Harness 的待办与日程面板。左侧是清单与日历，右侧是常驻的 AI 助手。

## 列表

- 按 **逾期 / 今天 / 本周 / 以后 / 未排期** 分组，顶部可按标签筛选
- **优先级有层次**：重要+紧急的行更高、字号更大、带红色左侧条；其余三档用色条与字重区分；已完成的任何一条都会缩到最小并变灰划线
- 距到期 0–2 天的时间标签变琥珀色，并直接显示「今天 / 明天 / 后天」
- 搜索：按标题与备注过滤
- 勾选即完成；删除有 5 秒撤销

## 编辑与新建

- **双击任意待办**进入行内编辑（删除按钮和勾选框除外），可改标题、日期、时间、标签、重要/紧急
- 改动后点外部不会退出，必须「保存」或「取消」（Esc 同取消）
- 「＋ 添加待办」打开的是同一套界面，只是标题为空

## 纪念日

- 日历视图右上角 **「纪念日 N」** 按钮，点开是本机保存的纪念日清单
- 清单按「还有几天」排序，显示类型色点、历法日期与剩余天数；点击任意一条进入编辑
- 支持 **生日 / 纪念日 / 忌日 / 其他** 四类，公历或农历（农历可勾闰月）
- 农历按年现算，边界已处理：农历三十遇小月落到廿九、公历 2/29 遇平年落到 2/28、闰月沿用「有则用闰月、无则用平月」
- 命中的日期会显示在日历格子里（粉色标签）

## 日历

- 7×6 月网格，含农历日、二十四节气、传统节日与重要日期（生日等）
- 滚轮翻月、年月选择器、「本月」回跳
- 农历表覆盖 1900–2100，离线计算

## 助手形象

- 点对话栏左上角的头像，打开形象设置：**名称** + **头像**
- 6 个预设头像；也可以上传自己的（会被压到 128px 存进本地存储，不落文件）
- 不设头像时回退成名字首字，完全不配置也能用
- 改名字后它会以新名字自我介绍 —— 名称会注入到系统提示词里

## AI 助手

- **真实流式**输出，不是打字机动画
- 粘贴截图或说一句话 → 拆成待办草案
- 草案卡**分条创建**：字段齐全的先建，缺日期的留在卡里继续补；创建过的条目打✓并锁定，不会重复提交
- 需要你决定时给**选项按钮**，点一下就等于回答
- 回复支持 Markdown 渲染
- **按需查库**：模型需要确认「有没有重复」时会调用 `query_todos` 查询，而不是把整份清单塞进上下文
- **能改也能删**：说要改哪条、删哪条，它会先查库定位（结果带 `[id]`），再用 `update_todo` / `delete_todo` 真正执行，改完列表立即刷新；删除前必须在对话里明确要求
- **时间锚点**：每轮注入当前时刻与时区，历史消息带时间戳；跨天对话会提示「之前说的明天按那条消息理解」

## 模型

默认**跟随 DSH 的默认模型**，不需要任何 API Key。也可以单独指定模型与思考等级（如 Low / High / Max），选择会持久保存。

## 数据与隐私

- 待办、对话、设置、重要日期都存在 DSH 的存储域里，不写工作区文件
- 插件代码不含任何密钥
- 只有你要识别的内容会发给模型

## 已知限制

- 法定节假日与调休不标注
- 农历超出 1900–2100 不显示
- 早期对话消息没有时间戳，历史中显示为「时间未知」
- 不支持删除单条消息，只能清空整段对话
- 助手的修改与删除都会**立即生效**，没有撤销（删除可在列表里用 5 秒内「撤销」找回）
