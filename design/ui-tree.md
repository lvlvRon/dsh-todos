# 待办面板 UI 树（v2 设计稿）

> 位置：`main` 面板（key `todos`）+ `sidebar.panellist` 图标（order 20，排在「任务」之后）
> 尺寸基准：主区 = 视口 - 宿主左侧栏；左看板弹性，右对话 392px 固定、可收起。
> v2 变更：加标签体系、优先级改为「重要 × 紧急」两维度、顶部四个视图、加标签筛选行。

## 位置说明（常被问）

最左边那一栏**是 DSH 宿主自己的左栏**，不是本插件的设计。插件只往 `sidebar.panellist`
里加**一格图标**，点它在主区打开本面板，与「对话」「插件」「任务」并列。
宿主左栏多宽、图标怎么排，由宿主决定；插件不改造它。

## 两个视图

时间范围控件**靠左**、紧跟标题；**视图切换固定在面板头正中**（`position:absolute; left:50%`，
不受左右两侧宽度影响），并且比常规控件大一档（38×32，图标 19px）—— 它是全局级的显示方式切换，
权重高于时间范围，所以单独放在视线中心。

时间范围口径：今天 = 逾期+今天；本周 = 前两者+本周；本月 = 日期落在当前月份的全部；
全部 = 含未排期；已完成 = 只看勾掉的。

- **列表视图**：日期卡 + 标签筛选 + 快速添加 + 分组清单。
- **日历视图**：
  - 固定 **7 列 × 6 行**（42 格），含上下月补位日期（整格压暗区分）。行高 `1fr` 均分，
    网格高度恒定，翻月不会跳动。
  - 每格左上：公历日 **17px**（周末红、今天品牌色加粗），右侧农历 11px。
  - 农历查 **1900–2100 离线表**（`data/lunar-table.json`，4 KB，由 lunar-javascript 生成并逐日校验）；
    初一显示月名（十月 / 十一月），其余显示日（廿三）。
    **不用浏览器内置 Intl** —— 实测它把 2027 年春节算成 2/7，官方是 2/6，差一天。
  - 节气绿色、传统节日红色；显示优先级：节日 > 节气 > 农历日。
  - 生日 / 纪念日单独成条（粉色），排在当天待办之前。
  - 滚轮 / 触控板上下划翻月：累积 36px 触发一格，300ms 节流；翻月带 200ms 位移淡入。
- 切到日历时，「今天 / 本周 / 全部 / 已完成」换成年月导航（‹ 2026 年 11 月 ›）。
  **点年月标题弹出选择器**：年份 ‹ › 步进 + 12 个月网格，当前月为实心、本月为品牌色；
  底部「回到本月」。范围钳在 1900–2100（与农历表一致）。
  **同一个位置承载同一个语义**（当前时间范围），不并排放两套互相打架的筛选。
- 标签筛选在两个视图都生效。

## 优先级：两维度、四象限

不再用「高/中/低」一维排序，改为艾森豪威尔两维，**同一色系（红）用浓度深浅表达优先级**：

| 象限 | 含义 | 浓度 | 图标高亮格 |
|---|---|---|---|
| Q1 | 重要 + 紧急 | 1.0 | 左上 |
| Q2 | 重要 + 不紧急 | 0.64 | 右上 |
| Q3 | 不重要 + 紧急 | 0.40 | 左下 |
| Q4 | 不重要 + 不紧急 | 0.20 | 右下 |

- 色相只有一个（`--prio-rgb`），四象限靠 alpha 区分；这样优先级只有一套视觉语言，
  不会和标签色、时间胶囊抢颜色通道。
- **行内**：15px 的 2×2 图标，只有所属象限那格实心，其余三格是 13% 同色淡底。
- **悬停**：图标上方浮出文字（`::after` + `data-tip`），例如「重要 · 不紧急」。
  默认不占任何版面 —— 说明只在需要时出现。
- **草案卡内**：两个开关「重要」「紧急」，图标实时联动；人可以直接改判断。
- 点图标可在四象限间循环（后续改成弹出选择器）。

## 帮助入口

右上角搜索图标左边一个 `?`，点开是浮层，收起所有说明性内容：

- 四象限图例（4 个真实图标 + 含义 + 建议动作）
- 操作清单（点圆环完成 / 点图标切换 / Ctrl+V 粘贴 / N 新建）
- 原型专用的主题切换（成品里没有这一项，主题跟随宿主）

对应地，页面底部**不再有任何常驻图例条** —— 说明性内容不占主界面。

## 标签

- 行内是**彩色圆点 + 灰色底**的小胶囊，不用彩色底，避免和时间胶囊、优先级色打架。
- 顶部一行筛选胶囊，兼当颜色图例；再点一次「全部」取消。
- 默认五类：工作 / 生活 / 学习 / 健康 / 财务。**可扩展**，存在域里而非写死。

## 计数口径（踩过的坑）

- 顶部日期卡：只算「逾期 + 今天」这一张盘子，因为它写着「今天」。
- 右上角胶囊：算当前视图可见的行数。
- 两者在「今天」视图下数字一致；切到「全部」时胶囊变大、日期卡不变 —— 这是有意的。

## 三条设计约束

1. 配色只用 `--dsw-alias-*`；`--q*` / `--tag-*` 是插件自己的语义色，明暗各一套。
2. AI 永不直接写库：只能在对话里产出 `DraftCard`，落库必须经过人点「创建」。
3. 信息密度向「今天」倾斜：切视图只改可见范围，不改排序。

## 字段模型

### 待办（一次性）

| 字段 | 类型 | 缺失时 |
|---|---|---|
| title | string | 必填（识别不出就不是一条待办） |
| dueDate | date | 虚线圈「缺日期」，阻断整体创建 |
| dueTime | string? | 缺省=全天，不阻断 |
| tag | enum/自定义 | 默认「未分类」，不阻断 |
| important | boolean | 默认 false，不阻断 |
| urgent | boolean | 默认 false，不阻断 |
| notes | string? | 不阻断 |
| rawText | string? | 原始短语（如「腊月二十八」），用来回显「我没解析错」 |
| remind | boolean | v1 占位，接口留好但未接引擎 |
| source | screenshot/text/manual | 自动，决定是否显示 ⚡ |

### 重要日期（生日 / 纪念日）

**不能存公历日期** —— 农历生日每年对应的公历都不一样：

| 农历 | 2026 | 2027 | 2028 |
|---|---|---|---|
| 十月十七 | 11-25 | 11-14 | 12-02 |
| 六月初三 | 07-16 | 07-06 | 07-24 |
| 腊月初八 | **2027-01-15** | 2028-01-04 | 2029-01-22 |

最后一行是关键：**农历腊月会跨公历年**，存公历必错。

| 字段 | 类型 | 说明 |
|---|---|---|
| label | string | 「妈妈生日」 |
| cal | `'lunar' \| 'solar'` | 历法系统 |
| month / day | number | 按 `cal` 解释 |
| leap | boolean? | 生日在闰月才需要。**策略 A**：当年有该闰月 → 走闰月；没有 → 走同名平月 |

渲染时按当前年份把 `cal: 'lunar'` 的条目换算成公历，再判断落在哪一格。
